# Firmware source

- `main/` contains the ESP32-P4 runtime, rendering, input and device protocols.
- `components/`, `assets/` and `config/` provide the firmware's build inputs.
- `tools/` contains image, font, built-in component and flash utilities.
- `tests/` contains host and SDK checks for firmware behavior.
- `main/pet_p4_voice_feedback.c/.h` hold bounded, capture-scoped PTT feedback and a real-PCM meter, compiled once at the existing size profile; the renderer keeps it inside the original 556×76 bottom strip. A confirmation key can submit only the currently visible voice draft when used with the matching desktop.
- `main/pet_p4_control_size.h` selects Oz only for explicitly marked low-frequency audio control and media-install metadata functions in WiFi6 v1; real-time workers, PCM/DSP and rendering retain their original options.

See [build and flashing](BUILD.md) for the four R284 release profiles and [device protocol](protocol.md) for the interface with the desktop client.
