# Firmware source

- `main/` contains the ESP32-P4 runtime, rendering, input and device protocols.
- `components/`, `assets/` and `config/` provide the firmware's build inputs.
- `tools/` contains image, font, built-in component and flash utilities.
- `tests/` contains host and SDK checks for firmware behavior.

See [build and flashing](BUILD.md) for the four R284 release profiles and [device protocol](protocol.md) for the interface with the desktop client.
