# 收尾配套音效

核心玩法或用途能完整使用后、最终打包发布之前，判断声音是否有实际价值。命中、成功、失败、计时提醒、乐器、互动反馈等适合补配套音效；安静的信息面板不必强加声音。

适合时只问一次自然语言问题，例如：“最后要配什么音效？简单说一下风格和哪些操作要响，也可以选不要声音。”用户已经描述过则沿用，不重复询问；不要让用户填写音频参数或 JSON。记录用户选择后生成，再验收真实触发。制作新声音不改变组件 ID、原存档和全局退出。

## 默认音效强度

新组件音效默认使用 **80%**。用户明确指定其他音量或不要声音时按用户要求执行；“轻柔”等风格通过音色、包络和节奏表达，不自行把默认强度降低。该默认值用于组件创作，不覆盖其他现有组件，也不修改设备系统音量。

- WASM 短单音使用 `hachi_tone(hz, ms, 80)`；声明式 `sfx.volume`、`sequence.volume`、`samples.volume` 默认写 `80`。
- 生成合成音效时，片段 `volume` 缺省为 `0.8`；显式数值保留，包括 `0` 静音。若播放路径另有组件音量参数，按上述规则设置，音量层级与实际听感分别验收。
- 播放、浏览器音效开关、录音/对话优先级仍遵循宿主约定；80% 不等于自动开启静音中的试玩或提高系统音量。

## 选择现有播放路径

- 简单按键提示优先用 [固定 sfx](sfx.md)，仅配置少量字节，无须音频文件。六个预设不能冒充任意采样音色。
- 旋律用 [sequence](component-media-events.md#合成音序)；原生 WASM 的短单音可使用 SDK `hachi_tone`。不要求额外安装 Python。
- 自定义短采样：声明式组件核验 `widgetSamples=p4-samples-v1` 并用 `runtime.samples` 引用 WAV；WASM 核验 `widgetWasmAudio=hachi-audio-v2`，将 HAB 音频库绑定 `hachi_sample(cue)`。按用户描述设计频率、波形、节奏与触发事件，不能只换预设名称。
- 真实动物叫声、语言或复杂拟音需要实际可用的音频生成能力或可合法使用的素材。程序波形只能做相符的合成音效，不冒称真实录音，不编造下载地址。
- URL 适合已支持的[设备联网音频](wifi-data.md#组件自定义网络音频)组件：真实设备宣告 `widgetWifiAudio=p4-wifi-audio-v1` 后，用 `media.source=wifi.audio` 与公开 HTTPS MP3/PCM WAV 曲目。保留用户发起播放、缓冲/失败状态、录音与实时对话优先、退出停止。它是媒体播放路径，不能把 URL 填进 `sfx`、`samples` 或 `hachi_sample`，也不能声称已有小游戏可直接把任意 URL 当按键音效。

URL 不随包内置音频文件，但仍消耗网络、缓存和播放内存，并非完全不占空间。需即时响应或离线可用的交互音效优先本地合成或小采样；远程播放失败时给出真实状态，不阻塞组件主要操作。没有相应宿主时说明限制并选可用路径，不静默改变组件用途。

## 30KB 配套音效预算

这次生成并打入包内的配套音效**所有文件合计不超过30,000字节**，包含文件头和索引，不能按单个文件计算，也不能只看 ZIP 压缩后大小。该预算针对配套音效，不是整个组件、历史语音库或远程播放缓存的格式上限。不要全局降低旧组件的兼容配额。

有 Python 时，Agent 可按用户描述生成声音规格，调用 `scripts/sound_effects.py`。它只生成短合成效果，输出16 kHz单声道 WAV（声明式，最多4项）或固件同格式 IMA HAB（WASM，最多64项），写入前核算总预算，超限拒绝，不静默截断。用自己的频率、时长和波形表达需求，下面只是音频规格语法，不是组件模板：

```json
{"cues":[{"id":"confirm","segments":[
  {"wave":"sine","ms":90,"hz":[660,990],"volume":0.8},
  {"wave":"triangle","ms":110,"hz":[990,1320],"volume":0.8}
]}]}
```

`wave` 为 sine/triangle/noise，`ms` 为10–8000整数；每个音效合计最多8秒；`hz` 是40–7000范围的起止频率，`volume` 为可选的0–1数值，缺省为0.8。noise 是合成噪声，频率参数不表示真实采样音色。前后短淡入淡出避免点击爆音。

```sh
python <skill-dir>/scripts/sound_effects.py generate effects.json /outside-package/sounds --format wav
# WASM 改用 --format hab，输出 speech.hab；cue 索引由生成报告给出。
python <skill-dir>/scripts/sound_effects.py check /path/to/final-effect-assets
```

先在组件外生成、试听，再只把正式引用的文件加入组件：WAV 是 `assets/<id>.wav`；HAB 是 `assets/speech.hab`。不把规格、生成脚本、试听副本或闲置音频留在包内。外部生成或取得的素材也必须检查最终文件合计预算；必要时主动缩短、合并提示音或改用设备合成，并保持用户要求的声音含义。

## 验收与交付

- 按真实按键或触屏事件走通每个声音的触发条件，检查声音和可见反馈一致；反复输入不造成失控叠播。
- 试听实际素材，检查首尾爆音、音量、明显失真和长静音；结构校验不能替代听感。
- 检查暂停、退出、录音/实时对话接管后停止；URL 路径另测缓冲、断网、失败与退出取消。
- 音效确定后重新打包、校验并运行受影响的回放。记录音效文件合计字节数与播放路径；依赖真机听感却没有实机条件时明确列出未验收项。
